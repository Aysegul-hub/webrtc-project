# WebRTC Video Chat

WebRTC kullanılarak geliştirilmiş temel bir görüntülü ve sesli görüşme uygulamasıdır.

## Özellikler

* 🎥 Kamera görüntüsünü alma
* 🎤 Mikrofon sesini alma
* 🔇 Mikrofonu açıp kapatma
* 📷 Kamerayı açıp kapatma
* 📞 Görüşmeyi başlatma ve sonlandırma
* 🔄 Görüşmeyi yeniden başlatabilme
* 👥 Karşı tarafın görüntü ve sesini gerçek zamanlı olarak alma

## Kullanılan Teknolojiler

* HTML
* CSS
* JavaScript
* WebRTC
* Node.js

## Proje

Bu proje WebRTC teknolojisinin temel çalışma mantığını öğrenmek ve gerçek zamanlı sesli/görüntülü iletişim uygulamasının temelini oluşturmak amacıyla geliştirilmiştir.
